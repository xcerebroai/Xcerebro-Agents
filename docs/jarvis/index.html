Getting started

After you download

Run the installer for your platform (one line, above). It sets up everything and creates a JARVIS launch point. On first launch, JARVIS will ask you to:

  1. Connect an AI provider key — paste an API key (e.g. Anthropic) so the agent can think.
  2. Connect Telegram (optional) — link a bot so JARVIS is reachable from your phone. WhatsApp and other channels add the same way.

Full steps and options are in the JARVIS README.
